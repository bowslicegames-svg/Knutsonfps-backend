# KnutsonFPS Minimal Backend (Node.js + Railway)

This is the minimal backend for KnutsonFPS.

## Features
- Player position sync
- HP sync
- Server-side damage
- Server-side grenade hits
- Killfeed
- Idle cleanup
- Fully in-memory (fastest)

## Run locally
npm install
npm start

## Deploy to Railway
Push to GitHub → Create Railway project → Deploy
